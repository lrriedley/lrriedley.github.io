Bar Ticket

Built it myself · 2026
Swift macOS Open Source

A menu-bar tool that watches my Swift projects for //TODO comments. Write one, hit save, and it opens a GitHub issue automatically — confirmed with a notch notification. No forms, no context switching.

I built it because my team runs project management through GitHub, and I was tired of leaving the editor to file a ticket every time I spotted a bug mid-feature. If you're writing TODOs in your own code, it's worth fixing that same problem for yourself.
